# Machine Learning Pipeline, Hyperparameter Tuning, and Ensemble Learning

Authors: Youssef Amin and Valerie Barker

## Project Structure

**src/**
Contains the source code for the project.

* **analysis.py** – Runs the project analyses and experiments.
* **bagging.py** – Implements bootstrap aggregating for SVC models.
* **data_loader.py** – Loads/flattens the MNIST and Fashion-MNIST datasets.
* **graphing.py** – Plots data and makes tables
* **models.py** – Defines dimensionality reduction and SVC models.

**data/**
Stores the datasets used by the project.

* **mnist/** – MNIST digit dataset files.
* **fashion_mnist/** – Fashion-MNIST dataset files.

**output/**
Stores results generated by the program.

* **images/** – Generated plots and figures.
* **tables/** – Generated tables of results.

## Running the Code

All modules inside `src/` are part of a Python package.
